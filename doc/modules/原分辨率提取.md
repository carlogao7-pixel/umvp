# 原分辨率提取 extract_faces（CropRestore）

> 模块组：人脸识别链路 | 代码：`umvp/pipe/crop_restore.py`
> 数据库参数：`EXTF0001`「原分辨率提取·默认」（presets 表 + preset_params_extract_faces 表）

## 1. 模块定位

从含人的原图中提取**原生分辨率**人脸：YOLO 识人 → 裁人（可放大）→
SCRFD 检脸 → 坐标还原 → 直接从原图裁脸。核心设计：人脸像素永远取自原图、
不经过任何缩放；放大只用于提升小脸检出召回，检出坐标再还原回原图。

配套工具类 `CropRestore` 提供"裁剪→还原"通用能力（画框坐标换算），
可单独用于任何"子图坐标 ↔ 原图坐标"场景。

## 2. 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| yolo_model | file | 空 | 识人用的 YOLO 权重（空=默认 yolov8n.pt） |
| yolo_conf | float | 0.35 | 识人置信度阈值 |
| yolo_iou | float | 0.7 | 识人 NMS 阈值 |
| yolo_imgsz | int | 640 | 识人推理分辨率 |
| yolo_max_det | int | 300 | 单帧最多目标数 |
| yolo_classes | str | "0" | 识哪类目标（0=人） |
| face_thresh | float | 0.4 | 人框内再检脸的阈值（SCRFD det_thresh） |
| upscale | float | 1.0 | 人裁剪图放大倍数：>1 提升小脸召回（只作用于"喂检测器的图"，出图仍是原分辨率） |
| margin | float | 0.15 | 人脸出图外扩比例（应对脸略超出人框） |
| min_person_short | int | 30 | 人框长边低于该像素直接跳过（太小检不出有效脸） |
| dedup_iou | float | 0.6 | 人脸去重 IoU：YOLO 重叠人框会让同一张脸进多个裁剪，超过它算同一张只留一张 |

`image` 为模块测试页的图片下拉参数（test_only，不落库、不进链路）。

当前库内值（EXTF0001）：全部默认值（yolo_conf=0.35, face_thresh=0.4,
upscale=1.0, margin=0.15, min_person_short=30, dedup_iou=0.6, yolo_classes="0"）。

## 3. 输入（必要字段）

| 字段 | 类型 | 内容 |
|---|---|---|
| img | ndarray (H×W×3, BGR) | **原帧/原图**：一切坐标的基准，人脸最终从它直接裁出 |
| bbox | (x1,y1,x2,y2) int | **画框位置**（CropRestore 工具单独使用时）：原图坐标系里的人框/目标框 |
| yolo | YOLODetector | 已配置 classes=[0]（人）的识别模块（extract_faces 编排内部用它识人） |
| face_det | FaceDetector | 人脸检测模块实例 |

编排入口 `extract_faces(img, yolo, face_det, tool=None, min_person_short, dedup_iou)`
只需前三个；工具方法 `crop_person(img, bbox)` 需要原图+画框位置。

## 4. 输出（字段和内容）

### 4.1 extract_faces() → list[FaceResult]

| 字段 | 类型 | 内容 |
|---|---|---|
| person_bbox | (x1,y1,x2,y2) int | 来源人框（原图坐标） |
| face_bbox | (x1,y1,x2,y2) int | 人脸框（原图坐标，含 margin 外扩后 clamp 图边界） |
| face_img | ndarray | **原分辨率人脸图**（从原图直接裁出，无缩放） |
| score | float | SCRFD 置信度 |
| kps | [(x,y)×5] float | 5 点关键点（已映射回原图坐标） |
| upscale | float | 检测时使用的放大倍数 |
| index | int | 全局序号 |

### 4.2 CropRestore 工具输出

`crop_person(img, bbox)` → `PersonCrop`：

| 字段 | 类型 | 内容 |
|---|---|---|
| img | ndarray | 裁剪图（已按 scale 放大，若 upscale>1） |
| offset | (ox,oy) int | 裁剪图左上角在原图中的坐标 |
| scale | float | 放大倍数（1.0=未放大） |
| bbox_orig | (x1,y1,x2,y2) int | 人在原图中的框（边界 clamp 后） |

`to_original(bbox, crop)` / `kps_to_original(kps, crop)`：裁剪图坐标系里的
框/关键点 → 原图坐标（除以 scale 加 offset）。
`extract_face(img, face_bbox_orig)` → (原分辨率人脸图, 实际裁剪框)。

## 5. 上下游衔接

- 上游：任意 BGR 原帧（+ 内部 YOLO 识人）。
- 下游：face_img 可直接归档/送人工；经人脸检测的对齐裁剪→人脸嵌入→底库，
  即组成完整人脸识别链。
