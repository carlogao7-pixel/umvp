# 警用无人机链路（唯一保留链路）

> 类型：模块自定义拼接链路 | 装配：`web_lab/server.py`（`_chain_from_spec` 装配，
> `_seed_pipeline` 播种） | 运行：`web_lab/test.html` 链路测试台
> 数据库：pipelines 表 `PIPE0001` + pipeline_steps 4 步（引用 4 条模块 preset）

## 1. 链路定位

唯一保留的完整链路：**帧管理 → YOLO 识人车 → VLM 研判警情 → 告警策略**。
面向警用无人机远角视频的四类警情监测（治安类/交警类/群体性事件类/救援救助类），
四个阶段全部由模块 preset 拼装而成，无链路专属代码分支。

## 2. 拼接结构（数据库存储）

```
PIPE0001 警用无人机链路（pipelines 表，streams=1）
 ├─ 步骤0  FM0001    警用无人机·帧管理      （frame_skip=15）
 ├─ 步骤1  YOLO0001  警用无人机·YOLO识别    （imgsz=1280, conf=0.25, 人≥2/车≥1 才报）
 ├─ 步骤2  VLM0001   警用无人机·VLM研判     （警情四分类提示词，真实端点调用）
 └─ 步骤3  AL0001    警用无人机·告警策略     （窗口判定 + 按警情类型独立冷却 30s）
```

链路只存"步骤引用哪些 preset + 顺序"（pipeline_steps），模块参数本体在各
模块参数表；每模块恰一份参数、链路恰一条，均由服务器启动幂等播种
（`web_lab/server.py` `_SEED_STAGES`，同名已存在则跳过、尊重 web 端编辑）。
各模块参数明细见 doc/modules/ 对应分册。

## 3. 数据流

```
视频帧 ──FM0001 要图决策（每15帧取1，积压自适应放宽）
            │ 要图的帧
            ▼
        YOLO0001 推理+过滤+按类报送 ── SubmitRequest(full:cls{N}) ──┐
            │                                                       ▼
            │                                          VLM0001 素材准备+真实推理
            │                                          （裁剪/缩放/警情四分类 prompt）
            │                                                       │ (alert_type, description)
            ▼                                                       ▼
        （dwell 类告警不走此链）                            AL0001 窗口判定+冷却
                                                                    │
                                                                    ▼
                                                            AlarmEvent（最终输出）
```

## 4. 运行方式（test.html 链路测试台）

打开 `http://127.0.0.1:8001/test.html` → 视频测试页：
选视频 + 选链路（PIPE0001）→ 运行。选视频后信息条实时显示**分辨率/帧率/总帧数，
并按链路帧管理的 frame_skip 与表单的时间段/最大处理帧数预估"将分析多少帧"**。
表单参数（`/api/test/pipeline_run`）：

| 参数 | 说明 |
|---|---|
| video / image | 测试视频 / 单图测试（二选一） |
| max_frames | 最多处理帧数（0=全部；注意是"读取帧数"，分析帧数=÷frame_skip） |
| start_time / end_time | 视频时间段截取（秒） |
| vlm_feedback | 是否把 VLM 研判结果回填告警（**关=只跑检测报送，开=完整闭环**） |
| vlm_action | 未接真实 VLM 时的模拟回填动作名 |
| output_dir / image_format | 关键帧与结果图落盘目录 / 格式 |
| max_saved_images | 落盘上限，默认 **200 张**（原图/标注图/人脸图共用计数；超限跳过写盘、时间线提示、结果头汇总） |

## 5. 输出

- **timeline 结构化时间线**：逐条 `{kind, text, data, ts, frame}`，
  kind ∈ frame（帧决策）/ submit（报送）/ vlm（研判）/ alarm（成警）/
  fail（VLM 调用失败）/ face / info（人脸链用）；前端分类渲染可过滤。
- **结果图网格**：关键帧/标注图/告警帧 data URL。
- **落盘**：output_dir 下关键帧与告警帧图片。
- VLM 真实调用失败时记 fail 条目继续跑，不中断整链。
