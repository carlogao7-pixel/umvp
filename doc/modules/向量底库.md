# 向量底库 FaceStore

> 模块组：人脸识别链路 | 代码：`umvp/face_embed/face_store.py`
> 数据库参数：`FSTO0001`「向量底库·默认」（presets 表 + preset_params_face_store 表）

## 1. 模块定位

人脸向量底库：注册（登记身份向量）+ 检索（Top-K 相似匹配）+ 持久化
（npz+json 文件）。零依赖 numpy 线性检索（千级底库 <1ms），同一身份允许多条
向量（多张登记照），检索按身份聚合取最高分。接口与 FAISS/LanceDB 对齐，
规模增大后可平替存储层。

## 2. 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| db_path | str | out/face_db.npz | 底库文件路径（.npz 向量 + 同名 .json 元数据）；不存在自动新建 |
| thresh | float | 0.45 | 检索阈值：相似度低于它不算命中（0~1，越大越严） |
| topk | int | 5 | 查询返回最像的前几个身份 |
| device | select | auto | 设备（测试台注册/查询前先检测+嵌入用） |

测试参数（仅模块测试页运行用，不落库、不进链路）：`action`（操作：register_dir/register_single/query/
self_check/list）、`register_dir`（注册目录，每张图=一个身份，文件名即身份名）、
`image`、`name`。

当前库内值（FSTO0001）：`db_path=out/face_db.npz, thresh=0.45, topk=5, device=auto`。

## 3. 输入（必要字段）

| 字段 | 类型 | 内容 |
|---|---|---|
| emb | ndarray (512,) | 人脸嵌入产出的 L2 归一化向量（注册与查询共用） |
| name | str | 注册时的身份标签（查询时不需要） |
| meta | dict，可选 | 注册附加元数据（如来源文件），随命中结果带出 |

## 4. 输出（字段和内容）

### 4.1 检索 → list[MatchResult]（按身份聚合，相似度降序）

| 字段 | 类型 | 内容 |
|---|---|---|
| name | str | 身份标签 |
| score | float | 余弦相似度 [0,1] |
| id | int | 命中向量在库中的序号 |
| rank | int | 命中排序（1=最相似） |
| meta | dict/None | 注册时附加的元数据 |

### 4.2 持久化

`save(path)` 落盘 `.npz`（向量矩阵）+ `.json`（names/metas/thresh）；
`load(path)` 读回。`stats()` 返回条目统计。

## 5. 上下游衔接

- 上游：人脸嵌入的 512 维向量。
- 下游：命中/未命中即业务结论（视频人脸检索链路的终点）；
  查询相似度也用于"与底库比对"式去重。
