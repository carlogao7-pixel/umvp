# 告警策略 AlarmPolicy

> 模块组：管道四模块 | 代码：`umvp/pipe/composer.py`（`AlarmPolicy`）
> 数据库参数：`AL0001`「警用无人机·告警策略」（presets 表 + preset_params_alarm 表）

## 1. 模块定位

告警判定与冷却：消费 VLM 研判结果（或驻留事件），按滑动窗口/驻留秒数/巡检
三种方式判定是否成警，并做冷却抑制（同一目标/警情类型在冷却期内不重复报）。

## 2. 参数

### 2.1 模块自身参数（落库为 preset）

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| kind | select | window | 判定方式：`window`=VLM 滑动窗口确认；`dwell`=目标驻留秒数；`inspection`=巡检（结果直接落盘不成警） |
| task_id | int | 1 | 任务编号，随告警事件带出（多任务/多路区分用） |
| target_actions | str | "fire,fight" | 目标动作/警情类型清单（逗号分隔）：VLM 研判结果命中其一才算告警；**空=巡检模式**（window 自动降级 inspection） |
| smooth_frames | int | 2 | 双语义：window=滑动窗口长度（连续看几次研判）；dwell=驻留秒数阈值 |
| hit_ratio | float | 1.0 | 窗口内命中比例达到多少才告警（1.0=全部命中） |
| alarm_cooldown | float | 60.0 | 冷却时间（秒）：告警后该 scope 多久内不重复报 |
| cooldown_by_action | bool | false | true=不同警情类型各自独立冷却（治安类报过不影响交警类）；false=同一目标统一冷却 |

### 2.2 测试参数（仅模块测试页运行用，不落库、不进链路）

`timeline`（事件时间线文本，逐行喂入模拟研判结果验证判定逻辑）。

### 2.3 当前库内值（AL0001）

`kind=window, task_id=1, target_actions="治安类,交警类,群体性事件类,救援救助类",
smooth_frames=1, hit_ratio=1.0, alarm_cooldown=30.0, cooldown_by_action=true`

要点：与警用链路 VLM 提示词配套——四类警情即 target_actions；窗口=1 表示
单次命中即成警（无人机场景研判频次低，不做多帧确认）；30s 冷却按警情类型独立。

## 3. 输入（必要字段）

### 3.1 VLM 结果回填（window/inspection）

| 字段 | 类型 | 内容 |
|---|---|---|
| track_key | int | 识别类型编号（与报送请求一致；整帧全局=-1） |
| action | str | VLM 研判出的动作/警情类型（如"交警类"） |
| ts | float | 事件时间戳（秒） |
| description | str，可选 | VLM 警情描述，随告警带出 |

### 3.2 驻留事件（dwell）

| 字段 | 类型 | 内容 |
|---|---|---|
| track_id | int | 目标跟踪 ID（YOLO track=True 产出） |
| cls_id | int | 目标类别（按类别记冷却） |
| ts | float | 事件时间戳（秒） |

## 4. 输出（字段和内容）

`on_vlm_result()` / `on_dwell()` → list[AlarmEvent]（空列表=未成警）：

| 字段 | 类型 | 内容 |
|---|---|---|
| task_id | int | 任务编号 |
| gran | str | 报送粒度（class/scene/per_track） |
| track_key | int | 识别类型编号（dwell 时为 track_id） |
| action | str | 成警动作：命中的警情类型 / `dwell:{cls}` / `inspection` |
| ts | float | 成警时刻（秒） |
| description | str | VLM 警情描述（dwell 无） |

## 5. 上下游衔接

- 上游：VLM 研判结果（window/inspection）或 YOLO 过滤后的逐 track 事件（dwell）。
- 下游：链路末端，告警事件即链路最终输出（web 时间线/落盘 JSON）。
