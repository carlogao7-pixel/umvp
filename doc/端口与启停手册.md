# 端口与启停操作手册

面向使用者：通俗说明。这份手册讲清楚项目占用了哪些端口、日常怎么启动、停止、重启，以及出了问题怎么查。

## 一、项目用了哪些端口

| 端口 | 服务 | 用途 | 默认绑定 |
|---|---|---|---|
| **8001** | web_lab 可视化测试台 | 浏览器里的调参/测试界面 | 127.0.0.1（仅本机可访问） |
| **3307** | 自含 MySQL | 网页上"命名配置"的暂存库（presets） | 127.0.0.1（仅本机可访问） |

两个端口都只绑在本机回环地址上，局域网/公网都访问不到，不用担心暴露。

- 8001 是主服务，浏览器打开 `http://127.0.0.1:8001/` 就能用。
- 3307 是它的附属数据库，由启动脚本自动拉起，平时不用单独操作。

## 二、命令速查

所有命令都在**项目根目录**执行。

| 需求 | 命令 |
|---|---|
| 启动（前台，适合开发调试） | `./web_lab/run.sh` |
| 启动（后台，关掉终端也不停） | `./web_lab/restart.sh` |
| 停止（web + 数据库全停） | `./web_lab/stop.sh` |
| 停止（只停 web，保留数据库） | `./web_lab/stop.sh --keep-mysql` |
| 一键重启 | `./web_lab/restart.sh` |
| 一键重启（数据库也一起重启） | `./web_lab/restart.sh --stop-mysql` |
| 换端口启动（例：8080） | `./web_lab/run.sh --port 8080` |
| 换端口重启（例：8080） | `./web_lab/restart.sh --port 8080` |
| 不用数据库启动 | `./web_lab/run.sh --no-db`（或 restart 同样支持） |

> 三个脚本共用一个入口风格：`run.sh`（启动）、`stop.sh`（关闭）、`restart.sh`（一键重启）。
> 端口参数一致，`--port N` 全局通用。

## 三、逐步说明

### 3.1 启动

**前台启动（开发用）**：终端里跑 `./web_lab/run.sh`，看到
`UMVP 可视化测试台已启动: http://127.0.0.1:8001/` 就说明成功了。
按 `Ctrl+C` 停止。这种方式下服务跟着终端走，关终端就停。

**后台启动（常驻用）**：跑 `./web_lab/restart.sh`，服务转到后台，关掉终端也不受影响。
日志写在 `out/web_lab.log`，想看运行情况用 `tail -f out/web_lab.log`。

无论哪种方式，脚本都会自动检查自含 MySQL 是否在跑，没跑就自动拉起，不用手动管数据库。

### 3.2 停止

- 前台跑的：直接 `Ctrl+C`。
- 后台跑的：`./web_lab/stop.sh`。默认会把 web 服务和自含 MySQL 一起停干净；
  只想停 web、保留数据库（比如数据库里存了想保留的命名配置）就加 `--keep-mysql`。

### 3.3 重启

`./web_lab/restart.sh` 一步完成"停掉旧进程 → 确认数据库在跑 → 后台拉起新服务"。
默认**不重启数据库**（数据库状态没必要每次动，重启更快更稳）；
如果改了数据库相关的东西想彻底重来，用 `./web_lab/restart.sh --stop-mysql`。

### 3.4 查看状态

| 想确认什么 | 命令 |
|---|---|
| 服务是否活着 | `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:8001/`（返回 200 即正常） |
| 两个端口谁在监听 | `ss -ltnp \| grep -E ':(8001\|3307)'` |
| 服务日志（实时） | `tail -f out/web_lab.log` |
| MySQL 日志（起不来时看它） | `tail -f .mysql/mysql.log` |

## 四、网页使用（web 手册）

浏览器打开 `http://127.0.0.1:8001/` 就是测试台主界面：**左侧栏导航，右侧是当前页面**。

左侧栏从上到下四块：

| 区块 | 内容 | 怎么用 |
|---|---|---|
| 模块分组 | 帧调度 / 管道模块 / 人脸识别链路 | 点一个模块，右侧出参数表单：调参 → 可存命名配置 → 点「运行测试」 |
| 已完成链路 | 搜索框 + 链路列表 | 点开一条（PIPE0001 警用无人机 / PIPE0002 车牌识别 / PIPE0003 人脸截取），可展开各阶段模块参数、改运行参数、运行 |
| 链路设计器 | 一个按钮 | 打开设计器：把模块排成阶段列表，设各阶段参数与资源预算，存成新链路 |
| 系统 → 数据浏览 | 只读表格 | 查看 MySQL 中 presets 注册表、各模块参数表、链路与步骤 |

**模块测试页**：页面顶部有资源估算区（预估显存/耗时），中部是参数表单，底部「运行测试」。
运行结果三件套展示：①运行日志文本 ②结构化表格 ③图片（标注图/裁剪图）。慢操作（模型加载）
会显示「运行中」，等几秒出结果。

**命名配置栏**：输入配置名 → 保存 / 载入 / 删除。同名字保存=覆盖旧配置；「数据浏览」页签
与它是同一份数据，只是只读视角。

**数据库不可用**：数据浏览页签显示「数据库不可用」，其它功能不受影响；见 FAQ Q3。

### 4.1 实时播放叠加（视频播放器 + YOLO 框同步）

`test.html`（视频测试台）支持「**同步播放运行**」：任务进行时同步播放所选视频，
并把检测框/车牌框实时叠在画面上。

- 用法：选链路 + 选视频 → 点「同步播放运行」；视频会自动跳到起始时间开始播，
  右上角状态条显示「处理中 N 帧 / 缓冲中 / 完成」；「停止同步」即中止。
- **视频编码适配**：素材多为 H.265(HEVC)，浏览器播不了（黑屏）。选视频时后端会自动
  判断，必要时转成 H.264 并缓存（`out/transcoded/`），页面显示转码进度，转完即可播；
  只需转一次，之后秒开。H.264 素材直接播、不转码。需要机器装有 ffmpeg。
- 原理：服务端 `GET /api/test/pipeline_run/stream`（SSE）逐分析帧推**框的数值**
  （不传图），浏览器本地播原视频 + canvas 叠加；**播放节流**——视频只播到"已收到
  结果的最新帧时间"就暂停等（缓冲），收到新结果再续播，故框与画面一致。
- 速度：**播放速度=处理速度**（CPU 上慢于实时，属预期）；抽帧（frame_skip>1）时
  非分析帧沿用上一分析帧的框。
- 约束：流式运行不做真实 VLM 调用（mock 回填由「VLM 回填」控制）；要真实研判用
  「开始测试」（批量运行）。
- 相关接口：`POST /api/test/pipeline_run/stop {run_id}` 停止；`/files/videos/*` 支持
  HTTP Range（可拖进度条）；设计细节见 `doc/实时播放叠加设计.md`。

各模块参数、输入输出的完整说明见 `doc/modules/`（每模块一篇）。

## 五、常见问题

**Q1：启动报"端口被占用"**
说明 8001 已被别的进程占住。先 `ss -ltnp | grep :8001` 看是谁，再决定：
要么停掉那个进程，要么换端口 `./web_lab/run.sh --port 8080`。

**Q2：换了端口启动，stop.sh 要加 --port 吗**
不用。`stop.sh` 优先按端口找，找不到会按进程名自动定位 web 服务，换过端口的实例也能停掉。
只有同时跑多个实例（多个端口）时才需要 `--port N` 指明确切停哪个。

**Q3：MySQL 起不来 / presets 保存报错**
`--no-db` 模式下 web 照常能用，只是"命名配置"存不了。检查 `.mysql/mysql.log`
看数据库的报错；实在不行用 `./web_lab/restart.sh --stop-mysql` 让数据库干净重来一次。

**Q4：停掉之后 `.mysql/` 里还有 mysql.sock 文件**
这是上次没干净退出留下的残留文件，不影响使用——下次 restart 会自动清掉再启动。
不用手动删。

**Q5：本机装过系统 MySQL，会不会被误停**
不会。脚本只按项目自己的 `.mysql/mysql.sock` 特征找进程，系统 MySQL 用不同的
数据目录和 socket，两者互不干扰。

## 六、端口参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--port N` | 8001 | web 测试台端口 |
| `--host` | 127.0.0.1 | 绑定地址，一般不动；改 0.0.0.0 等于对外暴露，不建议 |
| `--no-db` | 关闭 | 不连接也不启动自含 MySQL（presets 接口不可用） |
| `--stop-mysql` | 仅 restart.sh | 重启时连自含 MySQL 一起重启 |
| `--keep-mysql` | 仅 stop.sh | 停止时保留自含 MySQL |

数据库本身固定 3307、只绑本机，不提供改端口参数；连接参数可用 `MYSQL_*` 环境变量覆盖（见 `web_lab/db.py`）。
