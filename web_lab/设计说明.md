# 可视化测试台（Web Lab）设计说明

面向使用者：通俗说明，不贴代码。

## 一、这个东西是什么

一个跑在浏览器里的图形界面（网页工具），用来做两件事：

1. **调参数**：项目里每个模块的所有参数，都做成表单，在网页上直接改。
2. **单独测试**：每个模块可以独立跑一次，看到它输入什么、输出什么，不用再敲命令行。

它不改变任何现有模块的代码，只是把现有的模块"接"到一个网页上。

## 二、怎么启动

在项目根目录下执行一条命令，然后浏览器打开提示的网址（默认 http://127.0.0.1:8001）。
不需要安装任何新东西，用的全是系统自带的网页服务能力和项目现有依赖。

## 三、测试台里有哪些模块

按四组列出，每组之间互相独立：

| 分组 | 模块 | 测试时能调的参数（节选） | 测试输出 |
|---|---|---|---|
| 帧调度 | 抽帧调度器（FrameScheduler） | 抽帧间隔、积压阈值、放宽倍数、队列/自适应两种模式、模拟场景 | 逐帧"取/跳"决策表、间隔变化 |
| 管道四模块 | 帧管理（FrameManager） | 三种取图节奏（抽帧/墙钟秒/帧数）及各自参数 | 逐帧取图决策表 |
| 管道四模块 | 小模型识别（YOLODetector） | 权重、置信度、NMS、分辨率、类别、设备、过滤链、每类数量上下限、报送节拍 | 标注图片、检出清单、报送请求 |
| 管道四模块 | 大模型研判（VLMAnalyzer） | 外扩比例、缩放上限、提示词、素材包各字段；可勾选调用真实大模型 | 素材包内容（JSON） |
| 管道四模块 | 告警策略（AlarmPolicy） | 三种判定（滑动窗口/驻留/巡检）、命中比例、冷却时间、事件时间线脚本 | 告警事件表 |
| 管道四模块 | 四模式集成（compose） | 四种分析模式及全部配置字段，脚本化或真实图片驱动 | 每步报送/告警记录 |
| 人脸识别链路 | 人脸检测（FaceDetector） | 设备、阈值、检测分辨率、最多张数、对齐裁剪开关 | 标注图片、逐脸列表、对齐裁剪图 |
| 人脸识别链路 | 特征提取（FaceEmbedder） | 设备、输入图片（自动先检测再嵌入） | 每张脸 512 维向量概况 |
| 人脸识别链路 | 向量底库（FaceStore） | 阈值、Top-K、底库文件、注册/查询/自检/列清单操作 | 注册记录、命中结果、底库统计 |
| 人脸识别链路 | 原分辨率提取（extract_faces） | YOLO 参数、放大倍数、外扩比例、最小人框、去重阈值 | 标注原图 + 每张原生分辨率人脸 |
| 视频监控 | 视频扫描（FaceMonitor） | 视频文件、抽帧参数、限帧数、底库文件 | 扫描统计、命中记录、命中帧标注图 |

## 四、设计原则

1. **零新增依赖**：后端只用 Python 自带的网页服务，前端只用浏览器自带能力。
2. **参数即表单**：后端给前端一份"参数清单"（每个参数的名字、类型、默认值、说明），
   前端根据清单自动生成表单。以后模块加参数，只需在清单里加一行。
3. **测试结果三件套**：每次测试返回 ①运行日志文本 ②结构化表格 ③图片（标注图/裁剪图），
   网页上分开展示。
4. **不动现有代码**：所有测试都是"调用现有模块"，相当于把命令行测试搬进网页。
5. **慢操作可容忍**：模型加载第一次较慢（几秒），页面会显示"运行中"。

## 五、边界与说明

- 真实推理类测试（YOLO、人脸检测、视频扫描）需要用到模型权重，本机项目里已自带。
- 大模型研判默认不调真实端点（演示返回固定结果），勾选"调用真实大模型"并填端点/模型名后
  才发起真实请求。
- 视频扫描默认只扫前 60 帧（测试数据是 4K 长视频），可在表单里改限帧数。
- 每次测试在服务端排队执行（同一时间只跑一个），避免多个模型抢内存。

## 六、数据库可视化（数据浏览）

除了测试，测试台还多了一个"数据浏览"页签，把存在本机数据库里的**命名配置**做成
表格直接看。它和"命名配置暂存"是同一份数据，只是换个视角展示。

- **看什么**：当前有哪些命名配置（名字、类型、模块、保存时间），以及每个模块的
  参数明细——一个模块一张表，一个参数一列，像电子表格一样按模块看配置。
- **只读展示**：这里只负责"看"，不提供在线改/删，避免绕过"同名覆盖"等规则把数据
  弄乱；要增删改还是走"命名暂存"页面。
- **数据存在哪**：保存在项目自带的本地数据库里（首次点开时由服务器自动准备好表结构，
  不需要手工建库）。数据库没启动时，这个页签会显示"数据库不可用"，不影响其它功能。

## 七、验收标准

- 页面能列出全部模块，参数表单齐全。
- 每个模块点"运行测试"都有结果：要么是运行日志/表格/图片，要么是明确的报错。
- 纯逻辑模块（帧调度/告警策略等）秒级返回；真实推理模块（YOLO/人脸）几秒内返回。
- 不安装任何新 Python 包即可启动。
