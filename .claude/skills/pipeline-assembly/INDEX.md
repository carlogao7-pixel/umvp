# 链路拼接知识库索引（pipeline-assembly）

> 版本：v1.0（2026-08-11）。单一知识库，取代旧的"两个 agent 内联大段 + 两个 skill 文件夹"结构。
> 使用方：pipeline-architect（总装）与 pipeline-assembler（组装工）两个 agent 的基础提示词都指向本索引；
> 也可能被其他 agent / 裸 LLM 消费（任务包注入）。

## 这是什么

本目录是"链路组成环节"的全部所需知识，按 4 层分文件存放。两个 agent 的提示词只保留
基础内容（角色定位 / 边界红线 / 工作流骨架），详细知识一律在这里按需读取。

## 消费方式

- 【有工具时】读本索引 → 按任务需要读对应分层文件（见"分层总览"）。
- 【无工具时】由注入方按本索引把相关分层文件内容内联进提示词/任务包后交下游消费。

## 分层总览

| 层 | 内容 | 谁读 | 何时读 |
|---|---|---|---|
| L1-shared | 系统介绍 / 环境命令 / 模块速查 | 两 agent | 启动或首次需要时 |
| L2-architect | 意图识别 / 工作流 / 质量门与汇报 | 总装 | 对应工作流步骤 |
| L3-assembler | 壳模板 / 套路 / 工作流与汇报 | 组装工 | 写壳与交付阶段 |
| L4-experience | 决策表 / 坑 / 验证清单 / 先例 | 两 agent（粒度不同） | 方案设计与给建议时 |

## 维护规则

- 新坑 / 新决策 / 新模板 / 新验证结果 → 追加到对应分层文件，不新建散落文件。
- 新增或改名文件时，更新本索引的"文件清单"。
- 分层原则：陈述类（系统 / 环境 / 速查）→ L1；角色专属 → L2 / L3；经验类（决策 / 坑 / 清单 / 先例）→ L4。
- 权威源仍是 CLAUDE.md / 代码：知识文件是自包含快照，维护时以权威源为准同步。
