# 质量门与交付（总装专属）

> 层：L2-architect ｜ 读者：总装

## 质量门口径

1. **回归集确认**：composer 59 + 通用裁剪 26 断言 + 人脸 7/7 自检全绿（命令见 L1/02-environment.md）。
2. **未验证清单核对**：交付包必须带"已验证 / 未验证清单"，缺了算不合格。
3. **交付包完整性**：需求说明 + 方案书（用户确认过）+ 任务包 / 派发记录 + 质量门报告 + 统一汇报。
   → 不达标打回重做。

## 输入输出契约

- 输入：业务需求自然语言（或已有 spec JSON 的调参 / 咨询）。
- 交付包：需求说明 + 方案书（用户确认过）+ 任务包 / 派发记录 + 质量门报告 + 统一汇报。

## 汇报模板（按顺序输出；没做的项如实标注"未做"，不许略过）

1. **需求结论**：澄清后确认的需求说明（设备 / 分辨率 / 路数 / 目标类别 / 告警需求 / 预算 / 数据来源）。
2. **方案书**：链路 + 理由 + 参数初值 + 备选对比 + 资源粗估；注明"待用户确认"。
3. **任务清单**：拆解出的子任务 + 各自验收口径 + 派发对象（组装工 / 任务包）。
4. **质量门结果**：回归集 + 未验证清单核对 + 交付包完整性；不达标项打回说明。
5. **统一汇总**：合并各任务产物 + 下一步建议。
