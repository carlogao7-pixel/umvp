# 系统介绍（UMVP 通俗版）

> 层：L1-shared ｜ 读者：总装 / 组装工 ｜ 权威源：CLAUDE.md、doc/需求文档-业务版.md

UMVP（统一模块化视觉分析管道）是一套自包含的视觉分析系统：输入视频、图片或摄像头画面，
可以识别画面里的目标（人、车等）、识别人脸身份，判断异常行为，并按规则触发告警。
代码与模型权重都在项目内，独立部署。

## 管道四模块

| 模块 | 作用 |
|---|---|
| 帧管理 | 控制取帧节奏（抽帧 / 按时间 / 按帧数）与积压背压，防止处理不过来 |
| 小模型识别（YOLO） | 快速框出画面里的目标，快但"只认是什么"，不判"在干嘛" |
| 大模型研判（VLM） | 对送来的画面做语义理解（判断"在干嘛"），慢但懂内容 |
| 告警策略 | 根据报送序列判定是否告警（滑动窗口 / 驻留 / 巡检三种判定方式），带冷却防重复报警 |

## 链路拼接（不预设分析模式）

产品不预设固定分析模式，链路由**模块自定义拼接**：在 web_lab 链路设计器里按需选择
模块、逐阶段调参，存为「链路」——只记"用了哪些模块 + 顺序 + 各自参数"（数据库
pipelines + pipeline_steps 引用模块 preset）。当前项目仅保留一条链路：**警用无人机链路**
（帧管理→YOLO识人车→VLM研判警情→告警策略，PIPE0001）。

代码层另有 `compose(spec)` 的四模式封装（small_only / small_crop / small_full /
large_only），保留作脚本/回归测试兼容，不再是产品配置方式。

## 人脸识别链路

识人 → 按人裁图放大 → 精确检脸 → 提特征向量 → 到底库检索，回答"画面里的人是谁"，
人脸图保持原图分辨率。另有视频监控链路（抽帧 + 人脸检索持续扫视频）。

## 配套工具

- web_lab 可视化测试台：浏览器里选模块、填参数、跑测试、看结果；配置可暂存；带资源估算与实测标定。
- 资源估算：不跑模型先按公式粗估显存 / 内存 / 帧率；有本机实测指纹时更准；
  能按"多少路视频 + 多少显存预算"反推建议的抽帧间隔。

## 一句话价值

把"视频进来 → 目标 / 人脸 / 告警出去"的链路，从单个模块到整条管道，都能快速搭建、测试、估价。
