# mod-plate-repeat  (modify)

> 场景：同一个车牌被反复上报，怎么让它只报一次？
> 关注点：同车牌反复报：时序判定同对象一次/冷却
> 采集：2026-10-13 15:41

## 总装工（architect）
_ok=True steps=1 tools=[]_

您希望同一个车牌在检测到多次时，只触发一次报警。这可以通过设置“冷却时间”参数来实现。

### 分析

在车牌识别模块中，通常有一个参数叫做“冷却时间”，用于控制同一目标在多久内重复上报的阈值。例如，如果设置为5秒，那么在5秒内，即使检测到同一车牌多次，也只会触发一次报警。

### 操作

1. **定位模块**：首先，需要确定您的链路中使用了哪个车牌识别模块。常见的模块有“plate_recog”等。
2. **设置冷却时间**：在模块的参数中，找到“冷却时间”相关的参数，并将其设置为合适的值。例如，设置为5秒。

### 代码示例

以下是一个示例代码，展示了如何在“plate_recog”模块中设置冷却时间：

```json
{
  "module": "plate_recog",
  "params": {
    "track_cooldown": 5.0
  }
}
```

### 注意

* 设置冷却时间时，需要根据实际情况进行调整，以避免漏报或误报。
* 如果您的链路中使用了多个车牌识别模块，需要分别设置每个模块的冷却时间。
