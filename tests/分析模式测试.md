# 分析模式测试（填参表）

> 目的：为三种分析模式（small_full / large_only / small_only）各拼一条管道跑测试。
> 做法：每个模式一张表，把你想要测试的参数值填进"我的填写"列；空着的用默认值。
> 填完后的配置交给**装配器（compose）**组装成管道，即可逐帧喂入验证。

---

## 模式一：small_only（驻留告警，不送大模型）

**用的模块**：帧管理 + 小模型识别 + 驻留告警
**通俗行为**：小模型发现目标后，目标在画面里**待够 N 秒**就报警；全程不调大模型，最省算力。冷却按类别。

| 参数（中文） | 我的填写 |
|-------------|---------|
| 分析模式（固定填：small_only） |small_only |
| 任务编号（task_id） | 000001 |
| 抽帧间隔（extract_frame_rate，默认 3：每隔几帧取一帧） | 3 |
| 识别对象（类别：只盯哪一类目标，如 人 / 汽车，按实际模型的类别编号填；驻留秒数只对这一类算） | 人 |
| 驻留秒数（smooth_frames：目标在画面里待够几秒报警） | 5 |
| 识别对象数量上下限（class_limits：每个识别对象各配一组"下限~上限"，按过滤后该类目标数算；数量不在范围内的那一类不处理） | 人: 1~10 |
| 冷却时间（alarm_cooldown，默认 60 秒：报一次后多久不重复报；按类别冷却） | 60 |
| 过滤条件链（filters，已代填：置信度 ≥ 0.5；"只要哪些类别"已并入上面的识别对象） | 置信度 ≥ 0.5 |

## 模式二：small_full（按目标送全帧 + 大模型研判）

**用的模块**：帧管理 + 小模型识别（送**全帧**，带目标框标注）+ 大模型研判 + 窗口告警
**通俗行为**：发现目标后，把**整张画面**（目标框由拼接层画上）送大模型研判，大模型连续说中就报警。适合需要大模型看画面上下文的场景。冷却全局。

| 参数（中文） | 我的填写 | 
|-------------|---------|
| 分析模式（固定填：small_full） | small_full |
| 任务编号（task_id） | 000002 |
| 抽帧间隔（extract_frame_rate，默认 3） | 3 |
| 识别对象（类别：只盯哪一类目标，如 人 / 汽车，按实际模型的类别编号填） | 人 |
| 识别对象数量上下限（class_limits：每个识别对象各配一组"下限~上限"，按过滤后该类目标数算；数量不在范围内的那一类不送） | 人: 1~10 |
| 报送节奏（check_interval，默认 3 秒：同一识别对象隔多久允许再送一次，每类独立计时） | 3 |
| 报送粒度（固定为：按识别类型单独报送；一个画面里出现几类识别对象就送几条，一类多个目标合并成一条） | 按识别类型 |
| 送审缩放上限（vlm_max_resolution，默认 1280×720：画面太大先缩到多大） | 1280×720 |
| 裁剪外扩（crop_padding，默认 0.15：**全帧模式用不上，可留空**） | 0.15 |
| 提示词（vlm_prompt：告诉大模型看什么、怎么答） |  你是一个严谨的视觉分类器，负责对视频帧画面进行分析，判断是否存在目标动作。请按以下规则依次判断：

【治安类 - security】
画面出现打架斗殴、胁迫行为、抢劫、破坏公物行为

【群体事件类 - gathering】
画面中出现明显的人群聚集区域，

【交通类 - traffic】
画面中的车辆有明显的变形，或是在其所在道路的延申不远处有三角警示牌。

【救援类 - rescue】
失能倒地：人员呈非自然卧姿（俯卧/仰卧/侧蜷），或旁人有弯腰查看/搀扶动作。
溺水：水面有人员漂浮或肢体伸出水面。
受困/求助：人员在残骸、废墟、倒塌物近旁呈静止或挥臂姿态；或人员朝上方/远方大幅张开双臂、挥动衣物——此类"放大的肢体轮廓"是主动求救的俯视特征。

请根据上述规则，结合多帧画面进行综合判断，最终以 JSON 格式输出结果，格式为：{"result": "xxx", "description": "对检测到的警情的简要中文描述"}，其中 description 为一句简短的简体中文描述，说明画面中具体发生了什么。
无警情时，输出result="none"，无需额外描述 |
| 目标动作（target_actions：大模型判出哪些动作算命中；**留空 = 巡检模式**） | security、gathering、traffic、rescue（与提示词输出的 result 键一致；none=无警情不算命中） |
| 窗口长度（smooth_frames，默认 1：连续几次算数） | 1 |
| 命中比例（vlm_hit_ratio，默认 1.0：窗口内几次算"说中"） | 1.0 |
| 冷却时间（alarm_cooldown，默认 60 秒） | 60 |
| 过滤条件链（filters，已代填：置信度 ≥ 0.5；"只要哪些类别"已并入上面的识别对象） | 置信度 ≥ 0.5 |

## 模式三：large_only（周期性整帧送大模型）

**用的模块**：帧管理（**按秒取图**）+ 大模型研判 + 窗口告警
**通俗行为**：不依赖小模型，每隔 N 秒把整帧画面送大模型看一遍；不设目标动作时就是**纯巡检**（大模型说什么都直接记录）。冷却全局。

## 三种模式差异速记

| | small_only | small_full | large_only |
|---|-----------|-----------|-----------|
| 是否用大模型 | 不用 | 用 | 用 |
| 取图节奏 | 抽帧 | 抽帧 | 按秒 |
| 送大模型的内容 | — | 全帧（带框标注） | 整帧 |
| 告警判定 | 驻留秒数 | 滑动窗口 | 滑动窗口 |
| 冷却范围 | 按类别 | 全局 | 全局 |
| 最省算力？ | 最省 | 中等 | 看取图秒数 |
